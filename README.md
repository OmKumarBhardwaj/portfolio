# Om Kumar Bhardwaj — Portfolio

Personal portfolio: Senior Software Engineer · AI Engineer (AI agents + Java/Spring Boot backends).

- Built with Next.js (static export), Tailwind CSS, shadcn/ui and Magic UI.
- Based on the open-source template [dillionverma/portfolio](https://github.com/dillionverma/portfolio) (MIT).
- All content lives in `src/data/resume.tsx`.

```bash
pnpm install
pnpm dev      # http://localhost:3000
pnpm build    # static site in out/
```

Deployed on Netlify.
